3. Login, Logout, and Password Reset

Sign In

  1. Open /login or the website home page.
  2. Enter your email and password.
  3. Select Sign in.
  4. After successful login, the app opens the Dashboard.

Forgot Password

  1. On the login page, select Forgot password?.
  2. Enter the admin email address.
  3. Select Send reset link.
  4. In development mode, the reset token is displayed on screen.
  5. Open /reset-password, paste the token, enter the new password, and submit.

Logout

Use the Logout button in the top bar. This ends the local session and returns you to login.

5. Dashboard and Analytics

The Dashboard gives a quick view of campaign operations.

  • Review total contacts and sending metrics.
  • Check open rate, click rate, bounce rate, complaint rate, and unsubscribe activity.
  • Use Analytics for a higher-level performance view across campaigns.
Viewer users should use Dashboard and Analytics to inspect performance without editing campaign data.

6. Contacts

Use Contacts to create lists, add contacts, import CSV files, segment audiences, view contact history, and export list contacts.

Create a Contact List

  1. Open Contacts.
  2. Enter a list name and description.
  3. Select Create List.
  4. Select the list from the list selector to make it active.

Add One Contact

  1. Choose the target list.
  2. Enter email, first name, and last name.
  3. Select Save Contact.

Import Contacts from CSV

  1. Open Contacts, then select Import Screen, or open /contacts/import.
  2. Choose the target list.
  3. Paste CSV text with an email column. Example: email,first_name,last_name.
  4. Select Preview to check rows and column mapping.
  5. Select Import to save valid contacts.

Search, Sort, and Bulk Update

  • Use search to find contacts by email or name.
  • Sort by subscribed date, email, or first name.
  • Select contacts, choose a status, then use Bulk Update Status.
  • Select contacts and use Bulk Remove from List when they should no longer belong to that list.

Contact Detail

Select a contact email or View to open contact details. The detail view shows profile fields, list memberships, status, custom fields, and event history.

Segments

  1. Open Segments Screen or /contacts/segments.
  2. Enter a segment name.
  3. Select the operator: AND means all conditions must match, OR means any condition can match.
  4. Add rules such as custom.city equals Chennai.
  5. Select Create Segment.

7. Templates

Use Templates to create reusable email designs for campaigns.

Template Library

  1. Open Templates.
  2. Review existing templates by name and category.
  3. Select Create Template to add a new template.
  4. Select Edit to open the template editor.
  5. Use Duplicate to copy a template or Delete to remove one.

Template Editor

The editor has two modes: Blocks and HTML.

  • Blocks mode supports header, text, image, button, divider, spacer, two-column, three-column, social, footer, and custom HTML blocks.
  • HTML mode lets you edit raw email HTML directly.
  • Use merge tags such as {{first_name}}, {{last_name}}, {{email}}, {{custom.company}}, {{custom.city}}, and {{unsubscribe_link}}.
  • Use Desktop and Mobile preview to check the email layout.
  • Select Save Template after editing.
Always include an unsubscribe link in marketing emails. The available merge tag is {{unsubscribe_link}}.

8. Campaigns

Use Campaigns to create, send, schedule, pause, resume, cancel, duplicate, and report on campaigns.

Create a Campaign from the Campaigns Page

  1. Open Campaigns.
  2. Fill campaign name, subject, preview text, from name, from email, reply-to email, timezone, and tags.
  3. Choose a template.
  4. Select recipient lists that will be used when sending.
  5. Select Create Campaign.

Create a Campaign with the Wizard

  1. Select New Campaign Wizard.
  2. Details: enter campaign identity, sender fields, subject, preview text, timezone, and tags.
  3. Recipients: select contact lists, optional exclusions, or a segment. Use Estimate Recipients before continuing.
  4. Design: choose a template, or open the template editor if the design needs changes.
  5. Review: send a test email, then choose Send Now or Schedule.

Campaign Actions

9. Campaign Reports

Open a report from the Campaigns table by selecting View Report.

  • Review delivery, open, click, bounce, complaint, and unsubscribe metrics.
  • Inspect recipient-level engagement events.
  • Use Export CSV to download report data for offline analysis.

10. Suppression List

The suppression list prevents unwanted or unsafe sends.

  1. Open Suppression.
  2. Add an email address.
  3. Choose the reason: bounced, complained, unsubscribed, or manual.
  4. Select Add Entry.
  5. Use Remove only when the address should be allowed again.
Do not remove bounce, complaint, or unsubscribe entries unless you have a valid business reason and permission.

11. Organisation Settings

Only Super Admin users can access Organisation settings.

  • Update organisation name and logo URL.
  • Configure default sender email, AWS region, and SES configuration set.
  • Select Save Settings after making changes.

12. User Management

Only Super Admin users can manage other admin users.

  1. Open Users.
  2. Review the current user list.
  3. Enter name, email, role, and temporary password for a new teammate.
  4. Select Invite teammate.
  5. Use Refresh to reload the users table.

Available roles are Super Admin, Campaign Manager, and Viewer.

13. Profile

Every signed-in admin can update their profile.

  1. Open Profile.
  2. Edit name or email and select Save profile.
  3. To change password, enter the current password and new password.
  4. Select Update password.

14. Subscriber Pages

Subscribers do not log in. They use unique links inside received emails.

PagePurpose
/unsubscribe?uid=...Lets a recipient unsubscribe from campaign emails.
/preferences?uid=...Lets a recipient manage email preferences.

Campaign emails should include the unsubscribe link merge tag so recipients can opt out.

15. Recommended End-to-End Usage Flow

  1. Sign in as Super Admin or Campaign Manager.
  2. Create or import contacts into a contact list.
  3. Create segments if you need targeted audiences.
  4. Create or edit an email template.
  5. Create a campaign and select the template.
  6. Select recipient lists or a segment.
  7. Send a test email.
  8. Send now or schedule for later.
  9. Monitor campaign progress and reports.
  10. Review bounces, complaints, unsubscribes, and suppression entries.
