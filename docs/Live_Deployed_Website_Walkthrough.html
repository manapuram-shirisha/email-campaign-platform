Email Campaign Platform

Live Website Walkthrough

Step-by-step guide for opening and demonstrating the deployed website hosted with Vercel, Render, and Railway.

Websitehttps://project-f57re.vercel.app/
Web HostVercel
BackendRender API + Railway worker

1. Deployment Setup

PartPlatformWhat It DoesImportant Note
Frontend websiteVercelLoads the React admin website.The website page itself should open quickly.
Backend APIRender free tierHandles login, contacts, templates, campaigns, reports, settings, and tracking APIs.Free Render services can sleep when idle. The first request may take about 1 minute.
WorkerRailwayProcesses campaign sending jobs and scheduled campaign work.Used in the background after campaigns are sent or scheduled.
DatabaseManaged PostgreSQLStores users, contacts, lists, templates, campaigns, sends, events, and suppressions.The API and worker both connect to the same database.
Email/queue/storageAWS SES, SQS, S3Sends emails, queues campaign sends, and stores uploaded email assets.Production sending depends on correct AWS credentials and SES verification.
When showing the website to someone, open it and wait before judging login. Vercel may show the login page immediately, but Render may need around 60 seconds to wake the API. If the first login fails because the API is waking, wait and try again.

2. Open the Live Website

  1. Open https://project-f57re.vercel.app/.
  2. The Email Campaign Platform login screen should appear.
  3. If the page opens but login is slow, wait about 1 minute for the Render API to wake up.
  4. Try signing in again after the API wakes.

4. Best Demo Order

  1. Open the live Vercel URL.
  2. Wait for the Render API if the first login is slow.
  3. Sign in as Super Admin.
  4. Show the Dashboard and Analytics first.
  5. Show Contacts: lists, contact table, import, segments, and contact detail.
  6. Show Templates: library, editor, blocks, HTML, merge tags, and preview.
  7. Show Campaigns: create campaign, campaign wizard, recipient selection, test send, schedule, send now, and report.
  8. Show Settings: suppression list, organisation settings, profile, and users.
  9. Explain subscriber pages: unsubscribe and preference center links are opened by email recipients, not by admins.

5. Dashboard

After login, the Dashboard is the first screen. Use it to explain what the platform is for.

  • Total contacts shows the size of the audience stored in the system.
  • Emails sent shows campaign activity.
  • Open rate and click rate show engagement.
  • Analytics gives a broader view of campaign performance.

Demo line: This is the control center for checking campaign health before going into contacts, templates, and sending.

6. Contacts Walkthrough

Open Contacts

  1. Select Contacts from the sidebar.
  2. Review existing contact lists.
  3. Select a list to view its contacts.

Create a List

  1. Enter a list name and description.
  2. Select Create List.
  3. The new list appears in the list area.

Add a Contact

  1. Select the target list.
  2. Enter email, first name, and last name.
  3. Select Save Contact.

Import CSV

  1. Select Import Screen or open /contacts/import.
  2. Choose the target list.
  3. Paste CSV data with an email column.
  4. Select Preview to validate the file.
  5. Select Import to save the contacts.

Segments

  1. Select Segments Screen or open /contacts/segments.
  2. Create a rule-based segment, such as contacts where custom.city equals Chennai.
  3. Use segments later when choosing campaign recipients.

7. Templates Walkthrough

Template Library

  1. Select Templates.
  2. Show the saved email templates.
  3. Use Create Template, Edit, Duplicate, or Delete.

Template Editor

  • Blocks mode: add header, text, image, button, divider, spacer, columns, social links, footer, and custom HTML blocks.
  • HTML mode: edit raw email HTML directly.
  • Merge tags: use {{first_name}}, {{last_name}}, {{email}}, {{custom.company}}, {{custom.city}}, and {{unsubscribe_link}}.
  • Preview: switch between desktop and mobile preview.
  • Save: select Save Template after changes.
For a real email campaign, include {{unsubscribe_link}} in the template footer so recipients can unsubscribe.

8. Campaigns Walkthrough

Campaigns Page

  1. Select Campaigns.
  2. Use search, status filters, date filters, or tag filters to find campaigns.
  3. Review each campaign status: Draft, Scheduled, Sending, Sent, Paused, or Cancelled.

Create Campaign

  1. Enter campaign name, subject, preview text, from name, from email, reply-to email, timezone, and tags.
  2. Choose a template.
  3. Select recipient lists.
  4. Select Create Campaign.

Campaign Wizard

  1. Select New Campaign Wizard.
  2. Details: add name, subject, sender information, timezone, and tags.
  3. Recipients: select lists, exclusions, or a segment. Use Estimate Recipients.
  4. Design: select a template.
  5. Review: send a test email, then choose Send Now or Schedule.

Campaign Actions

ActionPurpose
EditModify a draft campaign.
View ReportOpen analytics for a campaign.
DuplicateCopy a campaign for reuse.
TestSend a test email before sending to the full list.
Send NowStart sending immediately.
ScheduleSet a future send time.
Pause / ResumeControl an active sending campaign.
CancelStop a campaign.
DeleteRemove a campaign when appropriate.
When a campaign is sent or scheduled, the API records the campaign work and the Railway worker processes queued sending jobs in the background.

9. Reports and Analytics

  1. Open Campaigns.
  2. Select View Report for a campaign.
  3. Review sent, delivered, opened, clicked, bounced, complained, and unsubscribed metrics.
  4. Use Export CSV if report data is needed outside the platform.

10. Settings Walkthrough

Suppression List

Use Suppression to block sends to addresses that bounced, complained, unsubscribed, or were manually suppressed.

  1. Select Suppression.
  2. Add an email and reason.
  3. Select Add Entry.
  4. Use Remove only when the email should be allowed again.

Organisation Settings

Only Super Admin can open this page.

  • Update organisation name and logo URL.
  • Set default from email and AWS region.
  • Save SES configuration set details.

Users

Only Super Admin can manage admin users.

  1. Select Users.
  2. Review existing users.
  3. Enter name, email, role, and temporary password.
  4. Select Invite teammate.

Profile

  1. Select Profile.
  2. Update name or email and save.
  3. Change password by entering current password and new password.

11. Subscriber Pages

Subscribers do not sign into the admin website. They use links inside emails.

PagePurpose
/unsubscribe?uid=...Recipient unsubscribes from emails.
/preferences?uid=...Recipient updates email preferences.

12. Live Demo Troubleshooting

ProblemLikely ReasonWhat To Do
Login page opens, but sign in is slow.Render free API is sleeping.Wait around 1 minute, then try login again.
Login fails immediately.Wrong account, unseeded production database, or changed password.Use the deployed admin account or seed/reset the production database.
Contacts, templates, or campaigns show loading/error.API is still waking or database connection is not ready.Refresh after a minute and check Render API logs.
Send Now does not send real emails.AWS SES/SQS/S3 or Railway worker may not be fully configured.Check Railway worker logs, AWS SES verification, SQS URLs, and credentials.
Images do not upload in templates.S3 bucket or credentials may be missing.Check S3 bucket, AWS credentials, and API environment variables.
Viewer cannot open Contacts or Campaigns.This is expected role protection.Use Super Admin or Campaign Manager for editing workflows.
